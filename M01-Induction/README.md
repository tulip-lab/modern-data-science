# Induction

This common-core module explains what Modern Data Science covers, how the shared modules fit together, how to find offering-specific support, and how assessment differs between universities and teaching periods.

After completing this module, learners should be able to:

1. describe the purpose and sequence of the Modern Data Science common core;
2. identify the learning and practical expectations relevant to their background;
3. locate the correct university and offering information;
4. distinguish reusable common-core guidance from current assessment and policy requirements.
