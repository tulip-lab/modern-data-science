# Modern Data Science Common Core

## Purpose

The common core provides reusable Modern Data Science learning content that can support multiple universities and teaching periods. Each offering may select, sequence, or supplement these modules, but institution-specific delivery and assessment rules belong in an offering layer.

## Common Learning Outcomes

After completing the relevant common-core modules, learners should be able to:

1. **Explain** the roles of data acquisition, storage, wrangling, analytics, and governance in a modern data science workflow.
2. **Use** Python and notebook-based environments to manipulate data and produce reproducible evidence.
3. **Acquire, clean, transform, and explore** structured and semi-structured data.
4. **Apply** distributed data-processing concepts and tools to appropriately scoped problems.
5. **Build and evaluate** selected predictive, anomaly-detection, forecasting, and pattern-discovery methods.
6. **Assess** privacy, responsible AI use, provenance, and limitations when communicating data-driven findings.

## Offering Use

An offering manifest should identify:

- the common-core version;
- the modules and learning outcomes used;
- offering-specific additions or exclusions;
- the public assessment alignment;
- official policy and delivery sources.

The manifest records alignment; it does not replace institution-approved unit documentation or policy.
